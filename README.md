# Auto Wohnung Search

Программа для Windows: следит за объявлениями об аренде жилья в Бонне, пишет арендодателям письма
на немецком через нейросеть и сообщает о результатах через Telegram-бота.

Основа — форк tg-autocomment. Запуск из исходников: `start.bat` или `python app.py`.
Тесты: `python -m pytest`.
