# Auto Wohnung Search

Программа для Windows: следит за новыми объявлениями об аренде жилья в Бонне, пишет арендодателям
письма на немецком через нейросеть и сообщает о результатах в Telegram-бота. Ответы арендодателей
приходят на ваш Gmail, программа их находит и пересылает вам в Telegram.

## Площадки

| Площадка | Статус |
|---|---|
| Kleinanzeigen | работает |
| WG-Gesucht | работает |
| Immowelt | скоро (нужно один раз пройти проверку «вы не бот») |
| ImmoScout24 | работает (один раз пройти проверку «вы не бот» при входе; для формы нужен адрес в `/profile address`) |

## Установка

1. Скачайте `Auto-Wohnung-Search-<версия>-Setup.exe` из раздела
   [Releases](https://github.com/NotoBoto/auto-wohnung-search/releases) и запустите. Права администратора не нужны.
2. Нужен установленный Microsoft Edge (есть в Windows 10/11): через него программа заходит на площадки.
3. Новые версии программа находит и ставит сама.

Запуск из исходников: `pip install -r requirements.txt`, затем `start.bat` или `python app.py`.
Тесты: `python -m pytest`.

## Первый запуск

1. **Gmail.** Включите двухэтапную аутентификацию (2FA) в аккаунте Google, затем создайте
   «пароль приложения» (Аккаунт Google → Безопасность → Пароли приложений). Введите адрес Gmail и этот
   пароль в окне программы. Обычный пароль от почты не подходит.
2. **Telegram-бот.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, получите токен и
   вставьте его в окно программы.
3. **Нейросеть.** Выберите в окне программы, чем писать письма, и укажите ключ или вход, если он нужен.
4. Откройте своего бота в Telegram и отправьте `/start`: бот запомнит вас как владельца и будет
   отвечать только вам.
5. Заполните профиль командой `/profile` (бот задаст вопросы по порядку). Данные из профиля идут в письма.
6. **Вход на площадки.** В окне программы нажмите вход для каждой площадки: откроется окно Edge,
   войдите в свой аккаунт вручную. Программа сохранит вход.
7. На самих площадках включите уведомления об ответах на e-mail (на тот самый Gmail), иначе программа
   не увидит ответы арендодателей.

## Команды бота

- `/start`, `/help` — привязка и список команд
- `/status` — состояние по площадкам
- `/pause [площадка]`, `/resume [площадка]` — пауза и возобновление (без аргумента — все площадки)
- `/mode auto|confirm [площадка]` — режим отправки
- `/filters [max_warm 950 min_rooms 3 min_lease_months 12]` — показать или изменить фильтры
- `/profile` — заполнить или показать профиль; `/profile <поле> [значение]` — изменить поле;
  `/profile hide|show <поле>` — скрыть или вернуть поле
- `/prompt` — показать промпт письма; ответом на сообщение с текстом — заменить
- `/cancel` — отменить текущий ввод

## Режимы

- `confirm` (по умолчанию) — бот присылает черновик письма, вы жмёте кнопку, и только тогда оно уходит.
- `auto` — подходящие объявления отправляются сразу, без вашего подтверждения.

Режим задаётся для всех площадок или отдельно для одной.

## Лимиты

Чтобы не вызывать подозрений, у каждой площадки есть дневной лимит писем (по умолчанию 15, для
ImmoScout24 — 10) и минимальная пауза между письмами. Опрос площадок идёт с случайными интервалами.
Когда лимит исчерпан, письма ждут в очереди до следующего дня.

## Предупреждение

Автоматические письма могут нарушать правила площадок. Аккаунт могут ограничить или заблокировать.
Используйте программу на свой страх и риск, не поднимайте лимиты и проверяйте тексты писем.
Автор ответственности за блокировки не несёт.

## Где лежат данные

Настройки, профиль, промпт, база и данные входа хранятся в `%APPDATA%\Auto Wohnung Search`.
Обновление программы их не трогает. При удалении установщик спросит, стирать ли их.

Основа проекта — форк tg-autocomment.
